# catalog-mcp MCP Server

Model Context Protocol (MCP) server generated by `fxkit gen mcp`.

## Quick Start

### 1. Run via Stdio (Claude Desktop / Cursor)
```bash
go run . --base-url http://127.0.0.1:8080
```

### 2. Configure with Claude Desktop
Add this to your `claude_desktop_config.json`:
```json
{
  "mcpServers": {
    "catalog-mcp": {
      "command": "/path/to/catalog-mcp",
      "args": ["--base-url", "http://127.0.0.1:8080"]
    }
  }
}
```

### 3. Run via HTTP JSON-RPC 2.0
```bash
go run . --transport http --port 9090 --base-url http://127.0.0.1:8080
```
